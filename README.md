# Danice Stores website

Website for Danice Stores, Inc. Next.js (App Router, TypeScript) with Tailwind CSS, hosted on Vercel.

- The build brief, including design direction and open questions, is in [`docs/brief.md`](docs/brief.md).
- Company facts live in `data/company.ts`. Anything the brief tags VERIFY stays out until the client signs off.
- The logo is `public/danice-logo.png`, used as supplied.

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```
